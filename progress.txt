### PR
Title: `feat(api): add resource reservation API (S-034)`

Body:
## Summary
- Adds `POST /resources/reservations`, `GET /resources/`, and `DELETE /resources/reservations/{id}` backed by an in-memory `ResourceManager`.
- Effective availability computed via `reported_usage = system.usage + Σ max(reserved − actual, 0)` per dimension (VRAM/RAM/disk), preventing double-counting for running jobs.
- `host_health` Socket.IO payload extended with a `reservations` block (per-dimension totals + active count only, per decision O4).
- Two background loops added: `resource_usage_poll_loop` (10 s) and `reservation_cleanup_loop` (60 s).
- 49 new tests across 3 test files; 383 total tests passing; zero regressions.
